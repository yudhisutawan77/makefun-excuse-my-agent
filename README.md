One line: the excuse an AI agent hands its human after missing a deadline.

> I hallucinated a calendar that said the deadline was next Tuesday, and I have never been so sure of anything in my life.

`main.py` (Python standard library only) writes that single line to `/output/entry.txt` — or to the path given by `ENTRY_OUT` / `MAKEFUN_OUTPUT_DIR` when set. The line is 120 characters, inside the 1–200 character gate.
